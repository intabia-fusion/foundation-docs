## Как создать встречу в планировщике

<div className="compact-list">
1. Нажмите на "Планировщик" в левом меню
2. В календаре выберите дату и временной слот, нажав на пустое поле соответствующее заданным параметрам.
3. Откроется модальное окно, где задаются параметры планируемого события:
   <div style={{ height: "4px" }}></div>
   <a href={invitelink1.src} target="_blank" rel="noopener noreferrer">
   <Image 
   src={invitelink1} 
   alt='Создание события в календаре' 
   inferSize
   quality='max'
   />
   </a>
   <div style={{ height: "4px" }}></div>

   - Название события
   - Время события
   - Продолжительность события
   - Повтор события
   - Часовой пояс события
   - Месторасположение
   - Участники встречи (можно добавить из существующего списка или добавить нового участника с возможностью внесения его контактных данных)
   - Создать встречу
   - Выбрать переговорную комнату из виртуального офиса
   - Добавить описание события
   - Добавить встречу в личный календарь
   - Установить приватность: видно всем, видно только вам, скрыть детали.
   - Добавить напоминание 

4. После заполнения полей, сохраните данные, чтобы создать встречу.
5. В календаре отобразится созданная встреча, открыв которую, можно скопировать ссылку или перейти по ней прямо из события.
