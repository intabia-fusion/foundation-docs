## Использование ресурсов

Посмотреть количество использованных ресурсов можно, нажав на иконку в верхней панели на любой страницы. Во вплывающем окне можно 
увидеть основные характеристики по условиям тарифа.

Более подробная информация находится в разделе “Биллинг” во вкладке “Использование ресурсов”. 

На странице отображается статистика по использованным ресурсам:
- размер файлов и количество файлов на диске,
- время транскрибации и количество токенов,
- суммарное количество минут по всем участникам,
- время записи,
- средняя продолжительность встреч,
- максимальная продолжительность встреч.
