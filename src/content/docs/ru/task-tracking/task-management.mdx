Отчеты по времени позволяют отслеживать трудозатраты по задачам всех участников команды в разрезе выбранного временного периода.



## Списание времени на задачу
Чтобы списать время на задачу через "Отчет по времени", необходимо:
 * навести на нужную ячейку в отчете и нажать на появившийся `+`
 * нажать на `+` внизу появившейся формы и выбрать задачу для списания. Одновременно из формы учета трудозатрат можно списать время на несколько задач
 * добавить затраченное время, описание работ. Так же в форме можно изменить выбранный день списания

Подробнее про работу с задачами см.раздел Управление задачами.
