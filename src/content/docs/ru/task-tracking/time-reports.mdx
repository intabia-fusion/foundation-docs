## Навигация по периодам
По умолчанию отчет отображается за текущую неделю.

Навигация по периодам происходит с помощью панели управления расположенной в правом верхнем углу:
* для переключения между периодами используйте кнопки для навигации `<` и `>`
* для быстрого возврата на текущую неделю нажмите кнопку `Сегодня` в правом верхнем углу
* для изменения периода отображения используйте переключатель периодов `Неделя`

Итоговые, общие показатели трудозатрат так же расположены в панели навигации. Трудозатраты по каждому из участников отображены в таблице отчета рядом с именем участника.


## Фильтрация задач
Для удобства работы с отчетами можно воспользоваться фильтрами. Нажмите кнопку `Фильтр` и выберите нужные параметры отбора (Проект, Исполнитель и т.д).

Или воспользоваться `Поиском`, который будет искать в выбранном периоде совпадения в названии задач, в описании задач и в активностях по задачам.


## Списание/редактирование времени через отчет
Чтобы списать время на задачу через "Отчет по времени", необходимо:
 * перейти в "Трекер"->"Мои задачи"->"Отчеты по времени"
 * навести на нужную ячейку в отчете и нажать на появившийся `+`
 * нажать на `+` в нижней части появившейся формы и выбрать задачу для списания. Одновременно из формы учета трудозатрат можно списать время на несколько задач
 * добавить затраченное время, описание работ. Так же в форме можно изменить выбранный день списания

## Удаление затраченного времени
Чтобы удалить списанные на задачу часы, необходимо:
* перейти в "Трекер"->"Мои задачи"->"Отчеты по времени"
* навести на нужную ячейку в отчете и нажать на списанные часы. Например `4ч`
* в открывшемся окне выбрать нужный день и нажать на строку правой кнопкой мыши
* нажать кнопку `Удалить`
